# Santa Rat Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add the Santa Rat character and a one-time "Merry Christmas" card that offers it, on Android and iPhone.

**Architecture:** The sprite is data in `characters.txt` (already drawn). The "is the card due" rule and the card content live in the shared module; Android shows the card from `MistyScreen`, the iPhone hosts it as a transparent overlay like the pin sheets.

**Tech Stack:** Kotlin Multiplatform shared module (Compose Multiplatform, kotlin.test), Jetpack Compose (Android), SwiftUI (iPhone).

**Spec:** `docs/superpowers/specs/2026-11-24-santa-rat-design.md`

## Global Constraints

- No emoji anywhere: code, strings, UI, docs, commits.
- Flag name: `rat_xmas_2026_seen`. Character id: `rat`.
- Texts in English (`shared/strings/values/strings.xml`) and Dutch (`shared/strings/values-nl/strings.xml`); keep the string names `character_rat_name`, `character_rat_blurb`, `rat_card_title`, `rat_card_body`, `rat_card_try`, `rat_card_later`.
- The card never shows before the first-run stage is `DONE`; "Not now" and a tap outside never change the selected character.
- Work on branch `rat-christmas`. Any on-device check uses the Dev app (`com.potloodgum.mistysteps.debug`) only, never unlocks the phone, and screenshots before every tap.

## Review Focus

- Card due while a first-run stage is still open (onboarding, consent, picker): must not show.
- Card already seen (flag set) after an app restart: must not show again.
- Phone in Dutch: Dutch texts show; any other language falls back to English.
- "Try the rat" when the rat is somehow missing from the character list: card closes, nothing crashes, character unchanged.
- Two quick taps on "Try the rat": selects once, sets the flag once, no double navigation.
